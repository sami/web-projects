## How I work

- I type every certification project myself, in line with the freeCodeCamp Academic Honesty Pledge. AI tools explain concepts and review my code, but they do not write the projects.
- Each project's README has a "How I used AI" section saying exactly what I used AI for.
- I write about what I learn in the Building the Web series on [sami.codes](https://sami.codes/blog).
